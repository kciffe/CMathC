                    一、 问题重述

1.1 问题背景

  大脑神经活动可以通过多种技术手段开展观测。按照采集时是否需要植入电极，脑电
采集手段可以划分为侵入式与非侵入式两类。脑电（EEG）是一类非侵入式神经观测手段，
凭借高时间分辨率、采集便捷的优势，广泛应用于认知神经科学、脑机接口与精神疾病相
关研究。相较于需要手术植入的皮层脑电图（ECoG），头皮 EEG 可以在无创伤条件下记
录大脑神经活动产生的电位变化。
  EEG 时序信号能够反映感知、认知过程下的神经动态，通过计算建模的方式，可以建
立神经活动与头皮观测信号之间的对应关系，用于解析脑电信号生成机理，对疾病辅助诊
断、脑机接口研究均有现实参考价值。
  头皮记录的 EEG 信号是大量神经元集群突触电位经过容积导体叠加后的观测结果。
利用头皮 EEG 观测反向还原底层脑内神经元活动属于病态源重建逆问题，直接求解难度
很高。单纯依靠数据驱动统计分析虽然可以获取干净脑电时序，但很难解释视觉刺激诱发
响应背后的神经生成机制。因此，微观 ‑ 介观 ‑ 宏观多尺度正向计算模型可用于从神经元、
神经集群再到大尺度脑网络层面仿真并解释视觉认知对应的脑电生成过程。
                                      。实验仅采集 F3、Fz、F4
  题目数据来自两组视觉认知实验（VisualCogA、VisualCogB）
三处前额脑电通道的原始信号，通过向受试者展示左、右三角形视觉刺激记录脑电响应数
据，要求完成脑电预处理、脑电正向生成建模、认知宏观模型构建整套递进式建模工作。

1.2 问题提出

                                  。其中，P300
  视觉刺激会在头皮记录中诱发与刺激和任务相关的事件相关电位（ERP）
（尤其是顶叶优势的 P3b）是经典的目标检测相关成分，通常在中央 ‑ 顶区分布。本题由于
仅采集 F3、Fz、F4 三个前额通道，观测到的主要为额叶 P3a 成分。然而，EEG 信号本身
幅值微弱，且易受到眼动、眨眼、肌电等多种伪迹的干扰，原始 EEG 数据中相关特征往往
被噪声淹没而无法直接观测。现有的多种降噪方案虽然能够去除伪迹，但同时也破坏了反
映视物形状的脑电特征。
  结合上述实验条件与建模难点，本文需要依次完成以下三项递进式建模任务：
  问题一：脑电信号降噪与曲线拟合。分别针对实验项目一和实验项目二，对给定的
EEG 数据进行预处理。要求在抑制眼动、眨眼、运动等伪迹的同时，尽可能保留与视觉刺
激和认知加工相关的事件相关电位（ERP）特征。提取 F3、Fz、F4 不同观测点位的有效视
觉响应，并拟合相应的曲线。该问题的核心挑战在于降噪过程中需要同时满足两个矛盾的
目标：充分去除伪迹以凸显有效脑电响应，以及完整保留与视觉刺激和认知加工相关的脑
电特征不被破坏。
  问题二：EEG 计算模型建立与左右三角刺激差异机制分析。建立从外侧膝状体核

                         5
（LGN）到大脑皮层，再到头皮观测的 EEG 正向计算模型，阐明脑电信号的生成机理。基
于该模型解释左、右三角形视觉刺激诱发脑电信号产生差异的内在机制，并构造可以区分
两类视觉刺激响应的特征表示。题目提示了神经生理学证据：颞下皮层的某些神经元对面
部的具象或简化表征（轮廓包裹双眼、双眼位于嘴部上方）产生强响应，而对缺失任一特
征的刺激响应微弱，这为建立形状特征与神经响应之间的联系提供了重要参考。
   问题三：认知宏观模型建立与验证。截取与视觉认知相关联的信号（其终点可能是应
答响应之前约 100 ms），借助问题二所建立的脑电信号形成机制，并考虑信号可能同时来
源于海马体和 LGN 等脑区，建立认知的宏观计算模型。利用题目提供的 EEG 信号验证该
模型的合理性。需要注意的是，被试的应答不一定正确，也可能出现未及时应答的情况，
建模时需考虑这一因素对信号分析的影响。
   本实验存在两项题目给定的硬性数据约束：全部分析仅可使用 F3、Fz、F4 原始 EEG
信号，禁止使用数据集自带 F3Decon、FzDecon、F4Decon 预滤波通道；试次 epoch 统一截
取范围为刺激 onset 前 0.2 s 至刺激 onset 后 1.0 s，并以 epoch 内刺激前的 200ms 区间作为
基线校正窗口。

                  二、 模型假设与符号说明

2.1 模型假设

2.1.1 问题一模型假设

1. 头皮 EEG 信号是大脑皮层神经元集群突触后电位经容积导体传导后的线性叠加，各通
  道记录的是同一神经源在不同位置的投影。
2. 实验仅使用 F3、Fz、F4 三个前额通道的原始 EEG，通道 4–6 的 Decon 数据已破坏视觉
  响应特征，故不采用。
3. 眼动、眨眼、肌电等伪迹在空间协方差结构上与干净 EEG 存在可分离差异，且伪迹试
  次与干净试次在统计上可区分。
4. 同一数据集内，干净试次的协方差矩阵服从同一分布，其黎曼重心可作为该数据集干
  净 EEG 的参考中心。
5. 削顶检测阈值 |x| ≥ 999 能有效标记饱和采样点；被标记的试次不参与 SQI 统计，但不
  改变原始波形。
6. 带通滤波采用前向-后向零相位滤波，不引入相位失真；降采样至 128 Hz 后仍保留 P300
  和形状相关 ERP 的主要频段信息。
7. ERP 基线校正窗口 [−0.2, 0) s 内不存在显著的任务相关 ERP 成分，以该窗口均值作为
  基线是合理的。
8. P300 候选峰主要出现在提示后 250–500 ms 和目标后 2.45–2.70 s 两个预设窗口内。
9. 条件平均 ERP 的 P-spline 拟合仅用于描述整段波形轨迹，不用于提取高斯参数。

2.1.2 问题二模型假设

1. 视觉刺激为左、右三角形，呈现时间约 0.2 s，忽略眼球运动对形状特征的破坏。
2. 物体识别基于特定空间排列的特征；左、右三角形的关键区别是顶点、垂直边和斜边
  的空间排列，而非整体朝向能量。
3. LGN 包含 TCR、IN、TRN 三类神经群，突触传递可用动力学模型描述，ON/OFF 通路
  存在约 9–11 ms 延迟差异。
4. V1、IT、前额叶等脑区活动可用 Wilson-Cowan 神经质量模型描述，区域间连接可用兴
  奋-抑制耦合表示。
5. 脑区之间的长程同步可用 Kuramoto 模型描述，序参数 r(t) 可调节源电流强度。
6. 皮层锥体细胞兴奋-抑制差形成偶极子源，经三层同心球头模型容积传导到头皮，导联
  场矩阵按解剖约束固定，不参与参数拟合。
7. 模型内部变量（LGN 响应、V1 朝向能量、IT 输出等）仅用于机理解释，不直接作为分
  类器输入，以避免标签泄漏。

3.1 问题一分析

   视觉刺激诱发的 P300 成分通常出现在刺激后 250 − 500 ms 的中央-顶区，幅度微弱，
极易被眼动、眨眼、肌电和运动等伪迹淹没。题目要求分别针对实验项目 1 和实验项目 2，
设计能够在保留视物形状相关脑电特征的前提下去除伪迹的方法，并提取 Fz、F3、F4 三
个观测点的有效视觉响应，拟合相应曲线。
   实验项目 1 中，受试者在目标出现前已知目标位置，只需等待目标出现；实验项目 2
中，受试者不知道目标具体位置，只知道目标形状。两个项目的认知任务不同，伪迹结构
也不同。项目 1 存在明显的左右位置提示，容易诱发方向性水平眼动、扫视和预期性眼动；
项目 2 需要比较左右三角形形状，形状相关 ERP 可能更弱，且易出现比较注视、眨眼和肌
电，但方向性眼动相对较弱。
   若对两个项目采用相同的固定阈值滤波或者简单试次剔除策略，容易过度去除携带真
实认知响应的 epoch。本文采用基于黎曼几何的低维多土豆自适应伪迹拒绝方法 [1]。该
方法将每个 epoch 表征为 Fz、F3、F4 通道的协方差矩阵，借助黎曼距离、迹和 Frobenius
范数构建多个黎曼土豆检测器；对各土豆输出的正异常分数进行等权加和得到综合异常分
数，进一步换算得到每个试次的信号质量指数 SQI。算法包含两处自适应阈值：其一在稳
健黎曼重心迭代阶段，根据各协方差矩阵到当前重心的黎曼距离计算稳健 z 分数，并采用
z ≤ 3 重建本轮参考集合；其二在所有试次 SQI 计算完成后，在低 SQI 区域寻找最大相邻
间隔，并取间隔右侧的 SQI 作为最终剔除阈值。由于仅使用 3 个通道，协方差矩阵维度低，
可避免传统黎曼土豆随传感器增多而敏感性和特异性下降的问题。
   原始 iRPF 算法配套土豆场依赖全脑分布多通道电极，不能直接迁移至本实验仅有的
三路额叶 EEG 数据；原版 iRPF 虽然可以通过数据驱动的方式得到自适应阈值，但并未设
计针对弱 ERP 场景的保守缩放机制，直接使用原始阈值，对项目二微弱的形状相关 ERP
容易造成过度剔除。针对项目 1 和项目 2 的伪迹与 ERP 特征差异，本文重新设计两套差
异化低维土豆场。项目 1 重点检测方向性水平眼动、眨眼和肌电，采用 4 个低维黎曼土豆，
并直接采用较严格的自适应阈值；项目 2 重点保护形状相关 ERP，采用 3 个低维黎曼土豆，
引入保守缩放系数，同时设置阈值下界 0.05，减少真实弱认知试次的误剔除。

3.9 本章小结

   本章针对实验项目 1 和实验项目 2，分别设计了基于黎曼几何的稳健自适应伪迹拒绝
方案，并对清洗后的 ERP 进行了候选峰提取与整段样条拟合。项目 1 重点检测方向性水平
眼动、眨眼和肌电，采用 4 个低维黎曼土豆；项目 2 重点保护形状相关 ERP，采用 3 个低
维黎曼土豆并放宽阈值。通过黎曼距离、迹和 Frobenius 范数等特征，结合稳健标准化、加
权异常分数与自适应阈值，得到每个 epoch 的信号质量指数 SQI。本文统一约定：SQI 越
大越干净，SQI 越小越异常，剔除 SQIi < τ 的 epoch。剔除坏 epoch 后叠加平均并提取候
选峰，进一步采用 48 个三次 B 样条基函数对整段 ERP 进行 P-spline 拟合，拟合优度 R2 达
到 0.891–1.000，RMSE 为 0.777–1.427。该方法仅使用 Fz、F3、F4 三个通道，计算量小，且
避免了高密度黎曼土豆的敏感性和特异性退化问题。项目一与项目二的差异化设计在当前
数据上实现了 Trial 级伪迹筛选；其中项目二通过减少土豆数量并采用更保守的 SQI 阈值，
降低了弱形状相关 ERP 被过度剔除的风险，为后续脑电计算模型提供了经质量控制的输
入数据。

              四、 问题二：视觉认知的脑电计算模型

4.1 问题二第一小问分析

   问题二第一小问要求建立脑电图计算模型，说明从 LGN 到皮层，再到头皮观测脑电
图的机理。该任务的核心是建立一个可运行、可计算、可逐层检查的正向模型，不以真实
EEG 分类准确率超过 0.5 作为完成条件。
   为此，本文建立如下正向计算链：

                  标准化视觉刺激与事件时序
               → 中心—周围滤波及 LGN ON/OFF 中继
               → Gabor 方向与三角构型表征
               → 早期、形状、方向三组 E/I 群体动力学
               → 六个突触滤波源电流代理
               → 固定几何导联矩阵
               → F3/Fz/F4 相对脑电曲线

   该链从刺激输入出发，逐层给出视觉中继、皮层群体响应、源电流代理和头皮观测之
间的计算映射。为便于阅读，下文将所使用的模型实现称为“修订版 V3（revision_v3）”，
以避免与视觉皮层 V3 混淆。需要强调的是，本文将“模型内部存在可计算的左右差异”与
“该差异已在真实头皮 EEG 中被稳定验证”分开报告：当前模型的实测验证强度受观测假
设和参数范围限制，因此结论限定在模型内部机制层面，不将模型写成已经确认的人体生
理真值。

4.2 模型建立与机理说明

4.2.1 原始刺激图像与圆形基线的像素级处理

   Stage1 的原始输入不是孤立的三角形：左右 cue 都是在共同的圆形基线上叠加三角提
示。令原始左、右 cue 灰度矩阵为 IL , IR ，共同圆形基线为 B，每张图像大小为 256 × 256。
修订版 V3 前端先将灰度归一到 [0, 1] 区间，再按像素计算带符号对比度：

                         IL − B                 IR − B
                  XL =          ,        XR =          ,   (4.42)
                           255                    255
   其中 IL , IR , B 均为原始灰度矩阵，除以 255 只执行一次，用于将灰度线性映射至单位
区间。圆形边缘在 cue 图和基线图中完全相同，所以相减后为零；三角区域由基线灰度 255
变为 cue 灰度 140，留下 (140 − 255)/255 ≈ −0.451 的负向亮度变化。因此，实际送入视觉
前端的是基线差分图，而非原始展示帧。共同圆形部分被抵消，而左右差异保留为镜像位
置上的三角变化。该步骤使模型不把共同背景圆当作左右判别线索。

4.2.2 左右差异是空间重排，不必是全场总量差

  标准左右 cue 在输入矩阵中互为水平镜像。若以 XL (x, y) 表示左 cue，则右 cue 满足


                 XR (x, y) = XL (W − 1 − x, y),    (4.43)

  其中 W 是图像宽度。对称视觉算子作用后，左右响应的总体能量可以接近一致，而
局部位置/方向响应按镜像关系重排。水平镜像下 0◦ 、90◦ 通道保持，45◦ 与 135◦ 通道交换；
因此只比较全局均值会压掉最有解释力的空间排列信息。
  图 4.17 上排显示的是实际视觉计算输入：原始 cue 图像逐像素减去共同的圆形基线后
得到的 signed contrast，不是原始展示帧。原始 cue 确实含有圆形基线和三角提示；由于两
者中的圆完全相同，逐像素相减后圆形部分抵消，只留下三角形区域的亮度变化。图 4.18
左列显示含圆形基线的原始 cue，后四列 Gabor 响应仍由 cue − 圆形基线 产生。三角形位

4.5 参数与模型范围

  四折拟合的 τs 候选都达到 100 ms 搜索上界，且优化器均未收敛。因此它们只能称为

一共享有符号增益；其符号也不能直接解释为真实偶极的生理反相。

   修订版 V3 当前拟合对象是 Stage1 左右 cue 条件 ERP，它不是直接以每个单试次的波
形拟合模型参数，真实单试次特征分类另行报告。当前 cue-only 模型没有生成 2.2 s 目标事

4.6 本章小结

   本节针对问题二第一小问，建立了从 LGN ON/OFF 视觉中继、皮层功能群体动力学、
源电流代理到 F3/Fz/F4 头皮观测的低维正向计算模型。模型主链为：标准化视觉刺激与
事件时序 → 中心—周围滤波及 LGN ON/OFF 中继 → Gabor 方向与三角构型表征 → 早
期、形状、方向三组 E/I 群体动力学 → 六个突触滤波源电流代理 → 固定几何导联矩阵 →
F3/Fz/F4 相对脑电曲线。
   模型揭示，左右三角刺激的主要可计算差异来自位置与方向的空间组合：全场汇总响
应可以近似相同，但空间化 Gabor/构型图在镜像位置上重新排列；在模型内部将位置编码
替换为其空间均值形成均匀图后，左右输出差异几乎消失。留出真实 EEG 对照则表明，当
前参数化和几何导联假设尚不能稳定复现实测差异；仅用真实特征跨记录分类的平衡准确
率和 AUC 分别为 0.453 和 0.421。在此基础上，采用记录特异的局部电极—时间窗与左右
ERP 模板进行模型分析之后的记录内读出，四份记录合并正确率为 54.2%（161/297），四
记录平衡准确率宏平均为 55.1%。因此，本模型完成了第一小问所要求的机制化计算表示，
并将其经验适用范围限定在现有证据之内；分类表现按记录报告，正向机制解释与实测读
出结果分别陈述。

 # This example formulates and solves the following simple MIP model
      :
 #    maximize
 #             x +   y + 2 z
 #    subject to
 #             x + 2 y + 3 z <= 4
 #             x +   y          >= 1
 #             x, y, z binary


 # import gurobipy as gp
 from gurobipy import * #GRB
 try:
          # Create a new model
          m = Model("mip1")
          # Create variables
          x = m.addVar(vtype=GRB.BINARY, name="x")
          y = m.addVar(vtype=GRB.BINARY, name="y")
          z = m.addVar(vtype=GRB.BINARY, name="z")
          # Set objective
          m.setObjective(x + y + 2 * z, GRB.MAXIMIZE)
          # Add constraint: x + 2 y + 3 z <= 4
          m.addConstr(x + 2 * y + 3 * z <= 4, "c0")
          # Add constraint: x + y >= 1
          m.addConstr(x + y >= 1, "c1")
          # Optimize model
          m.optimize()
          for v in m.getVars():
              print('%s %g' % (v.varName, v.x))
          print('Obj: %g' % m.objVal)


 except GurobiError as e:
          print('Error code ' + str(e.errno) + ': ' + str(e))


 except AttributeError:
          print('Encountered an attribute error')
