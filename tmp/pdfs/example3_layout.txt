                     1 问题重述

1.1 问题背景

  大脑神经活动可以通过多种技术手段开展观测。按照采集时是否需要植入电极，脑电
采集手段可以划分为侵入式与非侵入式两类。脑电（EEG）是一类非侵入式神经观测手段，
凭借高时间分辨率、采集便捷的优势，广泛应用于认知神经科学、脑机接口与精神疾病相
关研究。相较于需要手术植入的皮层脑电图（ECoG），头皮 EEG 可以在无创伤条件下记
录大脑神经活动产生的电位变化。
  EEG 时序信号能够反映感知、认知过程下的神经动态，通过计算建模的方式，可以建
立神经活动与头皮观测信号之间的对应关系，用于解析脑电信号生成机理，对疾病辅助诊
断、脑机接口研究均有现实参考价值。
  头皮记录的 EEG 信号是大量神经元集群突触电位经过容积导体叠加后的观测结果。
利用头皮 EEG 观测反向还原底层脑内神经元活动属于病态源重建逆问题，直接求解难度
很高。单纯依靠数据驱动统计分析虽然可以获取干净脑电时序，但很难解释视觉刺激诱发
响应背后的神经生成机制。因此本文引入微观 ‑ 介观 ‑ 宏观多尺度正向计算模型，从神经
元、神经集群再到大尺度脑网络层面，仿真并解释视觉认知对应的脑电生成过程。
  本研究基于两组视觉认知实验（VisualCogA、VisualCogB）开展。实验仅采集 F3、Fz、
F4 三处前额脑电通道的原始信号，通过向受试者展示左、右三角形视觉刺激记录脑电响应
数据，需要完成脑电预处理、脑电正向生成建模、认知宏观模型构建整套递进式建模工作。

1.2 问题提出

                                  。其中，P300
  视觉刺激会在头皮记录中诱发与刺激和任务相关的事件相关电位（ERP）
（尤其是顶叶优势的 P3b）是经典的目标检测相关成分，通常在中央 ‑ 顶区分布。本题由于
仅采集 F3、Fz、F4 三个前额通道，观测到的主要为额叶 P3a 成分。然而，EEG 信号本身
幅值微弱，且易受到眼动、眨眼、肌电等多种伪迹的干扰，原始 EEG 数据中相关特征往往
被噪声淹没而无法直接观测。现有的多种降噪方案虽然能够去除伪迹，但同时也破坏了反
映视物形状的脑电特征。

  问题一：脑电信号降噪与曲线拟合。分别针对实验项目一和实验项目二，对给定的

目标：充分去除伪迹以凸显有效脑电响应，以及完整保留与视觉刺激形状相关的脑电特征
不被破坏。
  问题二：EEG 计算模型建立与左右三角刺激差异机制分析。建立从外侧膝状体核

于该模型解释左、右三角形视觉刺激诱发脑电信号产生差异的内在机制，并构造可以区分

答响应之前约 100 ms），借助问题二所建立的脑电信号形成机制，并考虑信号可能同时来
源于海马体和 LGN 等脑区，建立认知的宏观计算模型。利用题目提供的 EEG 信号验证该
模型的合理性。需要注意的是，被试的应答不一定正确，也可能出现未及时应答的情况，
建模时需考虑这一因素对信号分析的影响。
   本实验存在两项题目给定的硬性数据约束：全部分析仅可使用 F3、Fz、F4 原始 EEG
信号，禁止使用数据集自带 F3Decon、FzDecon、F4Decon 预滤波通道；试次 epoch 统一截

基线校正窗口。

                  2 模型假设与符号说明

2.1 模型假设

  大脑神经活动可以通过多种电生理和神经影像技术进行观测。按照是否需要植入电
极，可将脑电记录方式分为侵入式和非侵入式两类。皮层脑电图（ECoG）通过在大脑皮层
表面布置电极获得神经电活动，具有较高的空间分辨率和信噪比，但需要手术植入，且长
期记录可能受到组织反应和电极界面变化等因素影响。相比之下，脑电图（EEG）利用头
皮电极无创记录神经活动产生的电位变化，具有时间分辨率高、成本较低、便于长时间记
录等特点，因此广泛应用于认知神经科学、脑机接口以及神经精神疾病研究。

                   3 问题一：脑电信号降噪与视觉响应提取

3.1 问题一分析

   视觉刺激诱发的 P300 成分通常出现在刺激后 250 − 500 ms 的中央-顶区，幅度微弱，
极易被眼动、眨眼、肌电和运动等伪迹淹没。题目要求分别针对实验项目 1 和实验项目 2，
设计能够在保留视物形状相关脑电特征的前提下去除伪迹的方法，并提取 Fz、F3、F4 三
个观测点的有效视觉响应，拟合相应曲线。
   实验项目 1 中，受试者在目标出现前已知目标位置，只需等待目标出现；实验项目 2
中，受试者不知道目标具体位置，只知道目标形状。两个项目的认知任务不同，伪迹结构
也不同。项目 1 存在明显的左右位置提示，容易诱发方向性水平眼动、扫视和预期性眼动；
项目 2 需要比较左右三角形形状，形状相关 ERP 可能更弱，且易出现比较注视、眨眼和肌
电，但方向性眼动相对较弱。
   若对两个项目采用相同的固定阈值滤波或者简单试次剔除策略，容易过度去除携带真
实认知响应的 epoch。本文采用基于黎曼几何的低维多土豆自适应伪迹拒绝方法 [1]。该
方法将每个 epoch 表征为 Fz、F3、F4 通道的协方差矩阵，借助黎曼距离、迹和 Frobenius
范数构建多个黎曼土豆检测器；对各土豆输出的正异常分数进行等权加和得到综合异常分
数，进一步换算得到每个试次的信号质量指数 SQI。算法包含两处自适应阈值：其一在稳
健黎曼重心迭代阶段，根据各协方差矩阵到当前重心的黎曼距离计算稳健 z 分数，并采用
z ≤ 3 重建本轮参考集合；其二在所有试次 SQI 计算完成后，在低 SQI 区域寻找最大相邻
间隔，并取间隔右侧的 SQI 作为最终剔除阈值。由于仅使用 3 个通道，协方差矩阵维度低，
可避免传统黎曼土豆随传感器增多而敏感性和特异性下降的问题。
   原始 iRPF 算法配套土豆场依赖全脑分布多通道电极，不能直接迁移至本实验仅有的
三路额叶 EEG 数据；原版 iRPF 虽然可以通过数据驱动的方式得到自适应阈值，但并未设
计针对弱 ERP 场景的保守缩放机制，直接使用原始阈值，对项目二微弱的形状相关 ERP
容易造成过度剔除。针对项目 1 和项目 2 的伪迹与 ERP 特征差异，本文重新设计两套差
异化低维土豆场。项目 1 重点检测方向性水平眼动、眨眼和肌电，采用 4 个低维黎曼土豆，
并直接采用较严格的自适应阈值；项目 2 重点保护形状相关 ERP，采用 3 个低维黎曼土豆，
引入保守缩放系数，同时设置阈值下界 0.05，减少真实弱认知试次的误剔除。

3.2 数据预处理

3.2.1 数据文件与通道选择

   题目提供四组实验数据：项目 1 为 VisualCogA_Task-1.mat 和 VisualCogA_Task-2.mat；
项目 2 为 VisualCogB_Task-1.mat 和 VisualCogB_Task-2.mat。每个文件包含 10 个通道：

  DataLabel = [Fz, F3, F4, FzDecon, F3Decon, F4Decon, ECC, VisCue, TgtAct, TimeStamp].


                                           8
   本文仅使用通道 1–3 的原始数据：Fz、F3、F4。通道 4–6 为机器自带滤波器处理后
的 Decon 数据，题目指出其会破坏视觉响应特征，故不使用。通道 7 为 ECG 心电，不作
为脑电参考；通道 8 为视觉提示 VisCue，通道 9 为 Action/TgtAct 目标应答，通道 10 为
TimeStamp。通道 9 用于记录点击反应，不参与 P300 提取。
   通道 8、9 的事件信号以及通道 10 的时间戳不参与 EEG 带通滤波，也不按普通连续信
号进行 Fourier 重采样。降采样阶段，VisCue 与 Action/TgtAct 按离散事件语义映射至新的
时间格，TimeStamp 则保留对应原始采样点的时间信息。
   四个数据集分别独立完成预处理、伪迹剔除和条件平均，不在不同 Task 或不同项目之
间合并 Trial。各数据集分别得到左、右条件的 ERP，用于后续比较。

3.2.2 事件检测与 Trial 切分

   首先在原始 VisCue 通道中检测从 0 变为 −1 或 +1 的第一个采样点，将该采样点定义
为视觉提示 onset。随后根据采样率构造相对时间轴，并将原始数据切分为提示 onset 前 1 s

3.8 本章小结

   本章针对实验项目 1 和实验项目 2，分别设计了基于黎曼几何的稳健自适应伪迹拒绝
方案，并对清洗后的 ERP 进行了候选峰提取与整段样条拟合。项目 1 重点检测方向性水平
眼动、眨眼和肌电，采用 4 个低维黎曼土豆；项目 2 重点保护形状相关 ERP，采用 3 个低
维黎曼土豆并放宽阈值。通过黎曼距离、迹和 Frobenius 范数等特征，结合稳健标准化、加
权异常分数与自适应阈值，得到每个 epoch 的信号质量指数 SQI。本文统一约定：SQI 越
大越干净，SQI 越小越异常，剔除 SQIi < τ 的 epoch。剔除坏 epoch 后叠加平均并提取候
选峰，进一步采用 48 个三次 B 样条基函数对整段 ERP 进行 P-spline 拟合，拟合优度 R2 达
到 0.891–1.000，RMSE 为 0.777–1.427。该方法仅使用 Fz、F3、F4 三个通道，计算量小，且
避免了高密度黎曼土豆的敏感性和特异性退化问题。项目一与项目二的差异化设计在当前
数据上实现了 Trial 级伪迹筛选；其中项目二通过减少土豆数量并采用更保守的 SQI 阈值，
降低了弱形状相关 ERP 被过度剔除的风险，为后续脑电计算模型提供了经质量控制的输
入数据。

 # This example formulates and solves the following simple MIP model
      :
 #    maximize
 #             x +   y + 2 z
 #    subject to
 #             x + 2 y + 3 z <= 4
 #             x +   y          >= 1
 #             x, y, z binary


 # import gurobipy as gp
 from gurobipy import * #GRB
 try:
          # Create a new model
          m = Model("mip1")
          # Create variables
          x = m.addVar(vtype=GRB.BINARY, name="x")
          y = m.addVar(vtype=GRB.BINARY, name="y")
          z = m.addVar(vtype=GRB.BINARY, name="z")
          # Set objective
          m.setObjective(x + y + 2 * z, GRB.MAXIMIZE)
          # Add constraint: x + 2 y + 3 z <= 4
          m.addConstr(x + 2 * y + 3 * z <= 4, "c0")
          # Add constraint: x + y >= 1
          m.addConstr(x + y >= 1, "c1")
          # Optimize model
          m.optimize()
          for v in m.getVars():
              print('%s %g' % (v.varName, v.x))
          print('Obj: %g' % m.objVal)
