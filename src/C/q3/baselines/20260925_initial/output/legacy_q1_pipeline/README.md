# Legacy Q1-derived artifacts

These files were produced by the earlier Q3 pipeline that copied or processed Q1 EEG epochs. The current Q3 pipeline reads the raw EEG records and writes `q3_raw_event_epochs.npz` and `q3_pre_response_epochs.npz` instead. The archived files are retained for traceability and are not inputs to the current Q3 analysis.

Archived files:
- `q3_eeg_trials.npz`
- `response_locked_eeg.npz`
- `response_window_processing.json`
