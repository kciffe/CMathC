# EEG 数据清洗说明：瞬时跳变、慢漂移与削顶饱和

## 1. 处理目的

针对原始 EEG 通道 `Fz`、`F3`、`F4` 进行数据清洗，重点处理三类问题：

1. **削顶饱和（clipping / saturation）**
2. **瞬时跳变（transient jump / spike artifact）**
3. **慢漂移（slow baseline drift）**

处理过程中不覆盖原始 `.mat` 文件，而是生成新的清洗后 `.mat` 文件，供后续 Trial 切分、基线校正、ERP/P300 提取使用。

## 2. 为什么只处理 Fz、F3、F4

题目数据中：

- 通道 1–3：`Fz`、`F3`、`F4`，为原始 EEG；
- 通道 4–6：`FzDecon`、`F3Decon`、`F4Decon`，为设备自带处理后的数据；
- 通道 7：ECG；
- 通道 8：视觉提示 `VisCue`；
- 通道 9：目标应答 / 动作 `Action`；
- 通道 10：`TimeStamp`。

由于题目明确说明设备自带去干扰结果可能破坏视觉响应特征，因此后续建模以原始 `Fz/F3/F4` 为主要输入。

## 3. 削顶饱和处理

### 3.1 现象

部分 EEG 信号长时间达到固定幅值上限，例如：

\[
x(t)=1000
\]

形成明显的水平平台。这说明采集系统发生幅值饱和，真实峰值已经丢失。

### 3.2 检测规则

设削顶阈值为：

\[
|x(t)| \ge 999
\]

连续满足该条件的采样点被认为属于削顶区间。

### 3.3 处理策略

- **短时削顶**：持续时间不超过 50 ms  
  使用 PCHIP（分段三次 Hermite 插值）结合削顶区间两侧正常数据进行局部重构。
- **长时削顶**：持续时间超过 50 ms  
  不直接伪造波形，将其标记为无效值 `NaN`，后续 ERP 分析时剔除包含严重削顶的 Trial 或对应通道。

## 4. 瞬时跳变处理

### 4.1 现象

瞬时跳变表现为相邻采样点之间出现远高于正常波动的突变，常见于电极瞬时接触变化、运动干扰或采集异常。

### 4.2 检测方法

先计算一阶差分：

\[
\Delta x_t = x_t - x_{t-1}
\]

然后在局部滑动窗口中计算中位数和 MAD：

\[
MAD = \operatorname{median}(|\Delta x-\operatorname{median}(\Delta x)|)
\]

利用：

\[
\sigma_{\mathrm{robust}} = 1.4826 \cdot MAD
\]

构造鲁棒阈值。当：

\[
|\Delta x_t-\operatorname{median}(\Delta x)| >
6\sigma_{\mathrm{robust}}
\]

时，将该位置标记为瞬时跳变候选点。

### 4.3 修复

对持续时间较短的异常段（默认不超过 30 ms）使用 PCHIP 局部插值修复。

## 5. 慢漂移处理

EEG 可能存在由电极极化、接触状态变化、皮肤电变化等因素引起的低频基线漂移。需要注意，低频变化不一定都是噪声，真实视觉认知过程也可能包含慢电位，因此不能使用过强的高通滤波。

当前采用四阶 Butterworth 高通滤波器：

\[
f_c = 0.1\ \mathrm{Hz}
\]

并采用零相位滤波 `sosfiltfilt`，以减少相位失真。

## 6. 为什么这里不做基线校正

慢漂移去除和基线校正是两个不同步骤。

当前步骤是在**连续 EEG 信号**上处理采集层面的慢漂移。后续按照视觉提示 `VisCue` 切分 Trial 后，再针对每个 Trial 的刺激前窗口进行基线校正，例如：

\[
[-0.5,0]\ \mathrm{s}
\]

对每个通道计算：

\[
\bar{x}_{baseline}
=
\frac{1}{N}
\sum_{t=-0.5}^{0}x(t)
\]

并进行：

\[
x_{corr}(t)=x(t)-\bar{x}_{baseline}
\]

推荐流程：

```text
原始连续 EEG
    ↓
削顶检测与处理
    ↓
瞬时跳变检测与处理
    ↓
0.1 Hz 高通去极慢漂移
    ↓
保存 clean.mat
    ↓
按 VisCue 切 Trial
    ↓
刺激前 [-0.5, 0] s 基线校正
    ↓
ERP / P300 提取
```

## 7. 输出文件

清洗程序生成：

```text
VisualCogA_Task-1_clean.mat
```

其中包含：

- `data_clean`：清洗后的完整 10 通道数据；
- `SampleRate`：采样率；
- `DataLabel`：通道名称；
- `clip_mask`：削顶检测掩码；
- `clip_repaired_mask`：已修复短时削顶掩码；
- `long_clip_invalid_mask`：长时削顶无效区间；
- `jump_mask`：瞬时跳变检测掩码；
- `jump_repaired_mask`：已修复跳变掩码；
- 相关处理参数。

原始 `.mat` 文件保持不变。

## 8. 论文中可直接使用的描述

> 针对原始 EEG 中存在的幅值饱和、瞬时跳变以及低频基线漂移问题，本文构建分类型数据清洗流程。首先，根据采集系统幅值上限识别连续削顶区间，对持续时间较短的削顶段采用 PCHIP 插值进行局部重构，而对长时间饱和区间不进行主观波形补偿，仅将其标记为无效数据，以避免引入人工脑电特征。其次，利用一阶差分与局部 MAD 鲁棒统计量检测瞬时跳变，并对短时异常段实施局部插值修复。最后，采用 0.1 Hz 四阶 Butterworth 零相位高通滤波去除极慢基线漂移，在抑制非生理低频趋势的同时尽量保留与视觉认知相关的事件相关电位特征。清洗后的连续 EEG 再依据视觉提示事件进行 Trial 切分，并在后续 ERP 分析中单独完成刺激前基线校正。

## 9. 参数汇总

| 参数 | 当前设置 | 作用 |
|---|---:|---|
| 采样率 | 256 Hz | 原始数据给定 |
| 削顶阈值 | `|x| >= 999` | 检测幅值饱和 |
| 短削顶最大长度 | 50 ms | 超过则不强行重构 |
| 瞬时跳变检测 | 局部 MAD | 鲁棒异常检测 |
| 跳变阈值 | 6 × robust sigma | 降低误检真实 EEG 波动 |
| 短跳变最大长度 | 30 ms | 局部插值修复 |
| 慢漂移高通截止 | 0.1 Hz | 去除极慢趋势 |
| 高通阶数 | 4 | Butterworth |
| 后续基线窗口 | -0.5～0 s | Trial 级基线校正 |

## 10. 后续验证

3. 检查 P300 候选峰值是否发生明显位置偏移；
4. 比较 F3、Fz、F4 三通道视觉响应保留情况；
5. 对不同参数进行敏感性分析。
