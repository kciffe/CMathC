# 问题二 revision_v3 诊断：群体活动拖尾、时间截断与滤波

## 结论摘要

新版模型的结构修正已经完成，但实测验证仍未通过。本次针对“群体响应持续偏高、800 ms 硬截断、零相位滤波影响、拟合未收敛”进行了定量诊断。结果表明：当前群体活动在 800 ms 时仍明显偏高，但延长模拟后会逐渐衰减；800 ms 后补零会反向改变 0–800 ms 的滤波波形；四个留出拟合均未收敛。因此，当前曲线不能据此解释为模型已能较好解释真实 EEG。

## 1. 皮层群体活动存在长拖尾

图 1 使用 `VisualCogA_Task-1` 的当前留出拟合参数，将 cue-only 模型从提示后 0 ms 延长到 3000 ms。提示实际持续约 203 ms。到 800 ms 时，构型组和三角模板偏好组的平均兴奋状态仍约为 `0.403`、`0.401`，对应抑制状态约为 `0.245`、`0.241`；而群体平均外部驱动已降至约 `0.0158`。到 2000 ms，后两组兴奋状态降至约 `0.0047`，至 3000 ms 接近零。

这说明高活动是**输入拖尾与群体状态缓慢衰减共同形成的长瞬态**；在本次代表性参数检查中，没有看到它长期维持为非零稳态。图中的状态均为模型归一化活动量，不能解释为神经元放电率。该轨迹来自未收敛的代表性留出参数，只用于定位问题，不是新的拟合结果。

![提示后群体活动的延长模拟与衰减](revision_v3_validation/persistent_activity_decay.png)

## 2. 800 ms 后补零会污染分析窗

第一问的 `7filter_downsample.py` 对完整的 `[-1, 3)` 秒试次进行 0.2–24 Hz、四阶 Butterworth 双向零相位滤波，再从 256 Hz 降至 128 Hz。当前 revision_v3 的模型曲线只生成提示后的 0–800 ms；`model_curve_to_q1_grid` 将其余时间补零后再执行同一观测算子。两边虽然调用相同滤波器，但滤波前的信号上下文不一致。

隔离审计把模型状态自然延长至 3000 ms，与 800 ms 后强制置零的版本分别经过相同滤波。在 8 个记录×左右提示条件中，0–796.875 ms 波形相对 RMSE 的中位数为 `0.154`，范围为 `0.123–0.166`。图 2 展示其中 `VisualCogA_Task-1` 的代表性对照，本例三电极相对 RMSE 为 `0.138`。这证明硬截断会改变拟合窗内波形，不能将其视为无影响的补零处理。

![800 ms 后补零对零相位滤波分析窗的影响](revision_v3_validation/zero_padding_filter_effect.png)

上述比较仍是 cue-only 隔离实验：它没有加入提示前的完整视觉背景，也没有加入 2.2 s 的目标事件。因此，下一版需要在完整试次时间轴上模拟背景、提示出现/消失和目标场景，再用同一滤波与降采样流程生成模型观测；不能只把 cue-only 输出延长后就认为上下文已经匹配。

## 3. 事件对齐与 EEG 参考状态

事件审计显示，四份记录的视觉提示 onset 中位数均为 `0 ms`，提示 offset 中位数均为 `203.125 ms`。因此提示事件锚点有记录内标记支持。目标出现的 `2.2 s` 则来自实验时序设定；当前清洗数据没有单独的目标视觉 onset 标记，`Action/TgtAct` 是行为响应通道，不能当作目标出现时间。

当前 MAT 的 `DataLabel` 包含 Fz、F3、F4、去噪通道、ECG、视觉提示、行为响应和时间戳，但没有记录头皮 EEG 参考电极的信息。revision_v3 简化导联采用连接乳突参考假设，因此真实记录参考与模型参考**尚未核实**。在正式重新拟合前，应从采集设置或第一问预处理记录确认参考方式，并让观测映射与其一致；不能把当前导联映射解释为已与真实参考匹配。

## 4. 拟合状态

当前四个 leave-one-MAT-out 拟合的 `optimizer_success` 均为 `False`，状态均为 `profile_grid_best_candidate_optimizer_not_converged`。每个留出模型在候选时间常数网格下进行了约 477–504 次目标函数评估，仍未得到收敛解；其中部分解到达参数边界。

因此，先前报告的平均留出 NRMSE 约 `1.82`、左右差异波相关约 `−0.18` 应视为**当前实现未能通过实测波形验证**。六特征 EEG 分类的 45.3% 是纯实测数据的另一项分析，不作为正向模型修正成功的证据。

## 5. 下一轮处理顺序

1. 将神经状态仿真扩展到完整 `[-1, 3)` 秒 epoch；在 cue 前按明确的实验背景设置初始视觉与群体状态，模拟约 203 ms 提示、提示消失后的背景，以及 2.2 s 目标场景。
2. 检查 cue 消失后的外部驱动和三组 E/I 状态：区分 LGN 适应拖尾、Wilson–Cowan 群体衰减与参数边界造成的慢响应。先报告输入、E/I 状态和源代理的数值范围，再决定是否需要改动力学参数。
3. 对完整模型试次使用与第一问一致的 0.2–24 Hz 四阶零相位滤波和 256→128 Hz 降采样；真实 EEG 不重复滤波。另做完整上下文、无目标上下文和 800 ms 补零三种观测对照，量化窗口内差异。
4. 核对真实记录参考与目标事件时间。参考元数据确认前，不把简化头模型的电极幅值当作与真实 EEG 同参考下的绝对预测。
5. 完成以上输入与观测口径修正后再拟合；报告优化器收敛状态、边界命中、训练/留出误差和波形差异。未收敛结果不作为机制拟合结论。
