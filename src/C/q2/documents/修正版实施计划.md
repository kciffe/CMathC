> 历史草案，已被[问题二项目实施方案](问题二_项目实施方案.md)取代。本文件的通道组织和参数扫描安排不再作为执行依据；保留仅用于追溯。

**Goal:** 保留现有基线，建立生理顺序明确、空间配置可检验、事件语义保守的并行实现，并用相同口径与实测记录比较。

**Architecture:** 图像增量→中心周围感受野/ON-OFF适应→LGN TCR-IN-TRN→V1四方向×8×8→IT单特征及相邻位置方向组合→群体电流代理→固定示意混合。去除无证据的PFC解剖解释。继承旧G但只报告其两个可观测模态，不反演六源。

**Tech Stack:** 现有 Python、NumPy、SciPy、Matplotlib、pytest。

**Spec:** [任务书](GPT-6Astra_问题二解决方案任务书.md)。用户明确要求直接建立修正版、运行并保留基线，因此在独立revision目录连续实施。

## 约束与检查重点

- 原01—05脚本和output原结果只读；新增revision/及output/revision/。
- Stage1 onset=0 ms、offset=200 ms；Stage2 onset=2.2 s且模拟800 ms内持续显示。无可靠刺激触发，固定时序是假设。
- 不使用Action符号推导Task2布局；只保留target_unknown汇总，不拟合未知混合比例。
- 参数训练与测试记录隔离，不称被试；低于10试次仅描述。
- G固定且rank=2；不调权重制造电极差异；模拟相对单位。
- 重点测试：镜像等变、空间打乱对照、offset事件、持续目标、标签未知隔离、训练记录隔离、截断峰、无有效参数时退回固定模型。

## 实施任务

- [ ] 1. config.py统一路径与时序；real_data.py加载真实数据与事件审计。先写未知标签和低试次策略测试，确认失败，再实现。
- [ ] 2. model.py实现保留空间的正向链。simulate(stimulus, stage, tau_it_ms=40, dt_ms=1)返回time_ms、LGN摘要、V1/IT特征、六源和三电极。先测零刺激、持续/消失输入及空间组合，再实现。
- [ ] 3. validation.py实现固定小网格IT时间常数选择（30/40/50/60 ms；延迟固定），按记录和阶段等权训练，边界峰约束；输出旧1.50基线、新固定40、新留一记录的同口径指标。训练内单一非负幅值系数，不拟合G/逐电极增益/时移。
- [ ] 4. 实测Stage1单试次预设窗均值与F4-F3特征，固定岭分类器、训练内标准化、留一记录平衡准确率；此为独立实测可分性验证，不能代替机制来源证明。
- [ ] 5. run_revision.py主链产出可重现数组/CSV/JSON/图；diagnostics.py检验镜像、空间打乱、dt减半及小参数扰动；运行主链和测试。
- [ ] 6. 独立复核代码，生成按任务书六部分组织的诊断与方案文档；报告真实改善或失败，不因完成实现声称模型已通过验收。

## 预先声明的验收

结构门：空间联合特征镜像可分且对空间打乱敏感；事件隔离正确；dt减半相对误差<5%。预测门：新模型相对旧基线总体记录等权r至少+0.02，至少3/4记录提高，两阶段均不下降；归一化幅值误差和拓扑不变差；无模拟边界峰，未截断峰误差不变差。实测可分性单独报告留一记录平衡准确率及分记录结果，不凭四折宣称显著。任何预测门不满足则保留为机制示意，旧基线仍作数值对照，不追加盲调。
