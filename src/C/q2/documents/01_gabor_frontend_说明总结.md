# 01 Gabor 视觉前端说明与结果总结

## 1. 模块目的

`01_gabor_frontend.py` 将标准化实验图像转换为后续 LGN/皮层模型可使用的两类输入：

1. **有符号亮度变化**：保留刺激出现或消失时亮度变化的正负号，供 LGN ON/OFF 通路使用。
2. **Gabor 空间方向响应**：保留刺激在不同空间位置、不同方向滤波器下的响应，用于后续空间编码。

该模块生成视觉特征，不执行分类，也不把 Gabor 对比输入当作 LGN 的有符号时间输入。

## 2. 输入与任务阶段

所有输入均为 `256×256` 灰度图，源 `.npy` 使用 `uint8`（0–255）。脚本读取后转为 `float32` 并除以 255，得到 `[0,1]` 亮度值。

| 任务/阶段 | 基线与目标 | 主要用途 |
|---|---|---|
| Task1 / Stage1 | 中央圆环基线 → 左/右三角提示 | 比较左右提示的 Gabor 空间方向响应 |
| Task1 / Stage2 | 白色基线 → 双圆点目标 | 以 4×4 空间亮度分布为主，Gabor 作为辅助描述 |
| Task2 / Stage1 | 与 Task1 共用左/右三角提示阶段 | 便于与 Task2 的 EEG 记录按阶段对应 |
| Task2 / Stage2 | 白色基线 → 相向/背向双三角 | 比较两种排列的 Gabor 空间方向响应 |

Stage1 的刺激及视觉结果在 Task1、Task2 目录中各保存一份；两份内容相同，便于后续按任务关联 EEG。Stage2 结果分别属于对应的任务。

## 3. 两类输入的计算约定

令 `B` 为基线亮度，`T` 为目标亮度，二者均已归一化到 `[0,1]`。

### Gabor 使用的正对比

```text
C = max(B - T, 0)
```

白底上的暗色刺激在 `C` 中为正值，未变化区域为 0。Gabor 滤波作用于该刺激增量，因此公共基线图形不会重复进入响应。

### LGN 使用的有符号亮度变化

```text
ΔI = T - B
```

暗目标出现时 `ΔI < 0`，目标消失、亮度恢复时 `ΔI > 0`。脚本分别保存 signed delta 与 Gabor contrast 数组，后续 ON/OFF 建模应读取 signed delta。

## 4. Gabor 与空间特征设置

- 滤波角度参数：`0°、45°、90°、135°`。
- 核尺寸：`31×31`；`sigma=4`、波长 `10`、纵横比 `gamma=0.5`。
- 每个角度分别计算余弦/正弦正交响应，并以平方和开方得到相位不敏感响应幅值。
- 空间方向 CSV 将每个响应图划分为 `4×4` 网格，记录每个方向、每个区域的平均响应及 A−B 差值。
- Task1 Stage1 的 A/B 为左/右提示；Task2 Stage2 的 A/B 为相向/背向双三角。

**角度解释注意**：代码中的 `theta` 是 Gabor 载波坐标的角度参数。按当前坐标变换，`0°` 表示载波沿 x 方向变化（条纹沿 y 方向延伸）。论文或后续模型若把角度称为“边缘/条纹方向”，应明确采用的是载波法向还是条纹走向。

## 5. 当前结果核对

当前结果由标准化输入和上述固定参数计算得到。Stage1 左右提示、Task2 Stage2 相向/背向双三角均具有相同的图形数量和尺寸；全局方向平均响应几乎相同，空间响应分布则不同，符合镜像/排列刺激的预期表现。

| 比较 | 各角度全局平均响应 | 全局 A−B 最大绝对差 | 4×4 区域 A−B 范围 |
|---|---|---:|---:|
| Stage1 左提示 − 右提示 | 约 `0.022195`、`0.018824`、`0.017956`、`0.018824` | `8.15×10⁻¹⁰` | `−0.145599` 至 `0.145599` |
| Task2 Stage2 相向 − 背向 | 约 `0.044390`、`0.037647`、`0.035912`、`0.037647` | `2.03×10⁻⁹` | `−0.153576` 至 `0.146371` |

表中四个全局响应值依次对应 `0°、45°、90°、135°`。全局差值接近数值计算精度；空间差异图和 CSV 保留 A−B 的位置分布，不应只用全局均值概括刺激差别。

Task1 Stage2 的双圆点目标方向性较弱，因此以刺激增量的 4×4 平均亮度作为主要空间特征，另保存 Gabor 响应作描述性结果。

这些数值是当前人工构造刺激及 Gabor 参数下的模型特征，不是生理参数估计、EEG 实测结论或分类准确率。

## 6. 输出目录

所有结果保存到 `src/C/q2/output/01_gabor_frontend/`：

```text
01_gabor_frontend/
├── Task1/
│   ├── Stage1/  # 左右提示的 signed delta、contrast、Gabor 响应/差异、PNG、CSV
│   └── Stage2/  # 双圆点的 signed delta、contrast、Gabor 辅助结果、空间亮度 PNG/CSV
└── Task2/
    ├── Stage1/  # 与 Task1/Stage1 相同的结果，供任务记录对应
    └── Stage2/  # 相向/背向双三角的 signed delta、contrast、Gabor 响应/差异、PNG、CSV
```

左右提示阶段在 Task1/Stage1 与 Task2/Stage1 中重复保存，是为了与两类任务各自的实验记录保持目录对应，并非两套不同的视觉输入。

## 7. 主要查看文件

Stage1 与 Task2 Stage2 各生成三张图：Gabor 方向响应总览、A−B 差异图、4×4 空间响应热图；并生成空间方向响应 CSV。Task1 Stage2 生成双圆点空间亮度热图和特征 CSV，另有 Gabor 辅助方向响应 CSV。

输出中的 signed delta、正对比及 Gabor 响应 `.npy` 均保留为独立中间数组，便于后续将 signed delta 接入 LGN ON/OFF 通路，将空间方向特征接入 LGN/V1 编码。

## 8. 运行

从项目根目录运行：

```powershell
.venv/Scripts/python.exe src/C/q2/01_gabor_frontend.py
```

脚本从自身目录下的 `input/` 读取刺激，并在 `output/01_gabor_frontend/` 下建立上述 Task/Stage 目录。
