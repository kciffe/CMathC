# 03_2 Cortex 诊断总结

`03_2_cortex_diagnosis.py` 读取 `output/03_cortex` 已保存的皮层源信号，检查条件差异在 V1、IT、PFC 逐层汇聚时如何变化，并检查 Stage1 左右提示是否近似镜像。它不重新运行 LGN 或皮层模型。以下数值对应当前经 Stage2 Fz 晚期峰时校准的 03 输出。

## Stage1 镜像关系与左右条件差异

左右提示经方向索引置换和空间水平翻转后，V1、IT、PFC 的镜像交换残差分别约为 $2.85\times10^{-7}$、$2.18\times10^{-7}$、$1.15\times10^{-7}$，接近数值精度范围。未镜像前的条件仍不同：

| 层级 | 左/右提示相对 L2 差异 | 平均绝对差峰值 | 差异峰时 |
|---|---:|---:|---:|
| V1 | 0.4360 | 0.009268 | 257 ms |
| IT | 0.1220 | 0.005539 | 313 ms |
| PFC | 0.0383 | 0.009728 | 329 ms |

这说明条件结构随层级汇聚而减弱，但未消失。镜像交换残差小表示左右两种输入近似镜像对应，并不表示左右条件本身相同。Stage1 的差异峰时也不是单一事件的潜伏期，因为模型同时包含 0 ms onset 和 200 ms offset。

## 指标定义与边界

相对 L2 条件差异定义为

\[
D(A,B)=\frac{\|A-B\|_2}{(\|A\|_2+\|B\|_2)/2}.
\]

平均绝对差峰值是各通道 $|A-B|$ 均值随时间的最大值。镜像交换残差比较一个条件与另一个条件经对应空间及方向翻转后的距离。它们均为确定性模拟的描述统计，不含试次抽样不确定性，不是显著性检验，也不能跨层解释成物理幅值比例。

这组诊断支持保留现有 03 作为简化基线：空间差异没有在 V1 到 IT 的映射中完全消失，但方向标签确实因平均而被压缩。若后续论文需要讨论方向选择性，应另设保留方向通道的模型作为对照，而不是把当前 IT 结果称为完整方向编码。
