# 问题二第一小问：架构诊断与修复路线

日期：2026-09-25。依据：题目原始 DOCX、revision_v2 实现、四份清洗 MAT、已有留出结果及本次定向数值诊断。

## 1. 先纠正目标与此前判断

原题第二问第一句是“建立脑电图计算模型，说明从LGN到皮层，再到头皮观测脑电图的机理”。随后才要求解释左右三角差异并给出区分特征。第一部分的核心交付是可计算的生理假设、群体动力学、源电流和头皮观测的衔接，并用数据说明适用范围。跨记录左右分类成绩不是该部分成立的先决条件。

此前将真实左右分类弱与正向 ERP 拟合失败过度关联，遗漏了 v2 自身的尺度和观测结构问题。本次已定位这些问题，不能继续将失败主要归于第一问数据。当前结果也不足以判定第一问清洗合格或不合格。

## 2. 已确认的模型问题

### 2.1 输入采用不同空间归一化，侧向输出压倒共同响应

`revision_v2/model.py` 的 `_project_half_fields` 对整幅图的一半取均值，而第三组方向输入直接使用三角中心附近的模板差响应。大量白背景稀释前两组，却不稀释第三组。

128 网格、默认参数下，三组驱动 RMS 分别为 0.0004165、0.0003286、0.0133873。方向输入约为前两组的 32 倍和 41 倍。群体模型又把第三组差值直接写入侧向模式 u1，并让所有模式共用一个增益。

本次对四个实际拟合解重新前向计算得到：

| 留出记录 | 模型 u1 能量占比 | 实测左右条件 ERP 合计 u1 能量占比 |
|---|---:|---:|
| VisualCogA_Task-1 | 99.938% | 7.963% |
| VisualCogA_Task-2 | 99.713% | 0.984% |
| VisualCogB_Task-1 | 99.668% | 6.771% |
| VisualCogB_Task-2 | 99.941% | 7.525% |

这里 u1=(F4-F3)/sqrt(2)。能量按 0–800 ms 实际采样点的平方和计算，左右条件等权。它说明当前数值接口造成严重的模式比例限制；不能据此直接把模型比例调成实测比例。

这也解释了为什么 rank-2 与 rank-3 几乎相同：第三模式虽在矩阵里存在，但实际产生的能量很小。增加矩阵秩没有解决源驱动尺度问题。

### 2.2 把神经功能直接绑定到传感器模式，强制了尚未证实的头皮对称性

`_readout_modes` 固定将 early common → u0、direction opponent → u1、shape common → u2。U 是传感器空间正交坐标变换，不是由源位置、方向及头部导电性质得到的导联场。它不能为上述神经功能分配提供依据。

镜像前端、独立同参数群体和该读出共同强制：

\[
\Delta\hat y(t)=a(t)(-1,0,1)^T/\sqrt2.
\]

因此模型规定 Fz 的左右条件差恒为零，F3/F4 差值必须等幅反号。刺激图像左右镜像本身不能推出这个头皮关系。三角朝向也不能直接等同于刺激所在视野或脑半球。

实测左右 ERP 差值能量落在 u1 之外的比例分别为 88.3%、65.5%、79.2%、99.9%。这些实测差异包含噪声，不能全部当作应拟合的神经信号；但模型的严格限制必须作为假设说明，不能宣称已由数据验证。

### 2.3 只放松最后的幅度仍不能解释现有时间波形

本次冻结每折已有动力学，仅在该折训练记录上将一个共享增益放松为三个模式增益。这是定位实验，不是新增正式模型，也没有使用留出记录估计增益。

| 留出记录 | 原共享增益 NRMSE | 三模式增益诊断 NRMSE |
|---|---:|---:|
| VisualCogA_Task-1 | 1.041 | 1.181 |
| VisualCogA_Task-2 | 1.000 | 1.008 |
| VisualCogB_Task-1 | 0.999 | 1.003 |
| VisualCogB_Task-2 | 1.000 | 1.001 |

本表 NRMSE 将左右条件、三模式和全部时间点合并计算 sqrt(SSE/实测平方和)，与此前逐条件 NRMSE 后取均值的汇总口径不同。零预测为 1。训练 NRMSE 即使放松幅度也仍为 0.991–0.999；所以末端独立增益不能救回当前轨迹。

当前 `_wc_populations` 是三组并行 E/I 动力学，组间无前馈连接；形状群体只是比早期群体多一个固定输入延迟。它可以作为单层功能群体模型，但不能称为已经实现 V1→IT 的时间级联。当前结果尚不能证明改变所有动力学参数都无效，只能确认已拟合轨迹与实测波形仍严重不匹配。

此前“群体没有过阈值所以无输出”的猜测也不能作为结论：激活函数在正输入处有连续响应，本次默认 E 最大值约 0.108，模型不是完全静默。

### 2.4 模拟和实测没有经过一致的观测处理

第一问 `7filter_downsample.py` 对每个 [-1,3) s 片段执行 0.2–24 Hz 四阶 Butterworth 双向滤波，再降采样。v2 将未经过该滤波的 0–800 ms 模拟曲线直接插值到实测时间点。实测有逐试次基线均值扣除；当前不是“完全没做基线”。

仅插值不能代替滤波、参考和基线处理。特别是双向滤波会使后续事件影响较早时间段。[MNE 滤波说明](https://mne.tools/dev/auto_tutorials/preprocessing/25_background_filtering.html)明确讨论了这种时间扩散。

本次构造仅在 2.2 s 出现的单位峰值平滑目标响应，使用第一问相同滤波器、四秒长度和 [-0.2,0) s 基线。原始 0–800 ms 信号严格为零，处理后该窗最大绝对值约为原始目标峰值的 8.82%。这只是合成探针，证明处理算子可以引入跨事件影响，不能据此声称真实提示 ERP 有 8.82% 污染。

### 2.5 评估混合了共同视觉响应与条件可分性

本次在每份记录内分别对左右试次随机分半，先算各条件均值，再等权取共同 ERP。500 次分半的共同 ERP 波形相关中位数为 0.744、0.977、0.573、0.942。共同平均波形有可重复结构，尽管其中也可能包含共同伪影或滤波影响。

因此“左右特征难分类”不等于“没有可建模的视觉相关平均曲线”。第一部分应先评价共同响应，再评价条件差异；不能把两者用单一分类分数替代。

## 3. 完成第一小问的最小修复路线

1. **统一前端驱动尺度。** 给早期和形状通路明确空间受体场及权重归一化，使用统一的刺激参考确定固定尺度。尺度在左右条件间共享，不按每张图单独归一化，不按留出 EEG 反推比例。首先消除全场均值与中心局部读出的无意稀释差异。
2. **建立明确的皮层源动力学。** 保留 LGN ON/OFF 与构型编码；用一个早期 E/I 群体和少量形状选择性 E/I 群体，给出明确的前馈耦合与时间常数。若只采用单层 WC，就诚实限制为单层皮层近似。onset 与 200 ms offset 均作为实际事件驱动，不预先把晚峰设成 P300。
3. **把源到头皮的机制补完整。** 将群体活动经兴奋/抑制突触核转换为源电流代理，再赋予少量固定源位置及偶极方向，使用标准球头模型计算 G。源位置和方向是建模假设，不由三电极自由反演。保留少量有界源组增益用于训练标定；不要把 u0/u1/u2 当神经源。三模式只用于分析结果。[MNE 正向模型说明](https://mne.tools/stable/auto_tutorials/forward/index.html)列出了源空间、头模型与导联场的关系。
4. **统一观测处理再拟合。** 使用 \(\hat y=\mathcal B\mathcal D\mathcal F\mathcal R[Gq]\)，其中 R 为参考算子、F 为滤波、D 为降采样、B 为基线。模拟完整必要时段和事件，再执行这些算子；若调整为连续数据滤波，实测和模拟一起更新。不能只在 0–800 ms 模拟曲线上直接滤波来冒充完整上下文。
5. **先做记录内留出试次的模型验证，再单列跨记录迁移。** 同一记录按连续试次块分训练/验证，条件比例保持合理。动力学和有限源增益仅用训练试次估计。分别报告共同 ERP、左右差分、各电极波形和零预测/简单经验时域模型对照。跨记录留出继续保留为更强的泛化检查，不能通过更换划分掩盖其失败。

最小源与观测关系可写成：

\[
q_k(t)=a_{E,k}(h_E*E_k)(t)-a_{I,k}(h_I*I_k)(t),\quad
\hat y_c(t)=\mathcal B\mathcal D\mathcal F\mathcal R
\left[\sum_k G_{ck}q_k(t)\right].
\]

这条链直接回答“LGN 输入如何成为皮层群体活动，群体活动如何产生等效电流，电流如何成为头皮观测”。无需先加入海马、Kuramoto 或生成式分类。三电极不足以唯一识别上述源与参数，所以最终只能解释所给假设下的前向机制，不能声称恢复了真实脑内布局。

## 4. 工程收尾与证据边界

- 拟合器在预算耗尽后返回上一候选点的目标值，这不是新参数的真实目标值。应正常停止并单列预算耗尽，不让优化器继续看到人工常数。本次保留的最优候选来自实际评估，但不能只凭状态字符串称整个参数搜索已充分收敛。
- 不主张用三个自由模式增益作为正式修复；本次该对照已经失败。源的统一尺度和合适时间动力学需要在前向链内部解决。
- 基线回归可作为第一问的预处理敏感性比较；现有逐试次基线均值扣除已存在，基线回归不能解决本报告发现的模型尺度和源映射问题。[MNE 基线回归示例](https://mne.tools/stable/auto_tutorials/epochs/15_baseline_regression.html)解释了它与传统基线扣除的区别。
- 本轮只诊断，未改写 v1/v2 的动力学、拟合参数或原有结果。新增数值证据见 `../output/revision_v2/architecture_diagnosis.json`。
- 可以完成第一小问的机理模型与计算演示，但目前不能保证修复后真实 EEG 留出拟合达标，更不能保证真实左右分类显著。若新的共同响应拟合仍不能优于合理基线，应把结论限定为机制假设和数据不支持之处。
